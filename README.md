# prueba-tecnica
Para la prueba técnica estaré trabajando en este proyecto durante el transcurso de los siguientes dias.

Un Sistema que Gestiona Proyectos Técnicos de alumnos.

Para el Backend voy a utilizar:
-Base de datos MySQL en un contenedor Docker
-Lógica en Javascript con Node.js y Express
-La configuración va a ser mediante docker-compose.yml
-Uso variables para credenciales y configuración

Para el Frontend voy a utilizar:
-Una interfaz web con HTML, un poco de CSS y Javascript
-Voy a estar utilizando Visual StudioCode para desarrollar
-Quiero aclarar que mi foco inicial estaría en la lógica del backend y la conexión con la base de datos, pero la web es para que se visualice mejor el proyecto, aunque sea de una forma básica.
